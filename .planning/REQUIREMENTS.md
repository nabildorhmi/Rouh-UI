# Requirements: Rouh

**Defined:** 2026-07-29
**Core Value:** A visitor immediately understands Rouh does two distinct things well — brand/marketing services and podcast studio rental — and the site feels polished and trustworthy enough to convert them into a booked call.

## v1 Requirements

### Podcast Studio Repositioning

- [ ] **STUD-01**: Visitor sees rental packages framed as "rent our studio + gear to record your own podcast" — not "pay to appear as a guest on Rouh's show"
- [ ] **STUD-02**: Visitor can see an itemized equipment/gear list (mics, cameras, lighting, capacity) for each rental package
- [ ] **STUD-03**: Visitor can see rental package details (session duration, gear tier, dry-hire vs. staffed option) with no explicit price shown, consistent with the Agency page's pattern
- [ ] **STUD-04**: Visitor can find studio location and logistics info (address, parking, access notes) on the Podcast page
- [ ] **STUD-05**: Visitor can read a studio-specific FAQ covering cancellation/reschedule policy, session length, staffing option, and room capacity
- [ ] **STUD-06**: Visitor can browse a photo gallery of the studio space using generic/placeholder imagery (real photography not yet available)
- [ ] **STUD-07**: Visitor booking a studio session goes through the existing reservation flow driven by corrected package data, with no guest-appearance language remaining anywhere in the form copy

### Marketing Copy

- [ ] **COPY-01**: Visitor reads final brand-voice copy (not placeholder text) for all Agency services, Agency plans, Podcast studio packages, and section copy sitewide
- [ ] **COPY-02**: No page on the site (Home, Agency, Podcast, Contact, nav, footer) contains stale guest-appearance language ("guest," "our show," "featured guest," etc.)

### Trust & Social Proof

- [ ] **TRUST-01**: Visitor can read testimonials from Agency clients
- [ ] **TRUST-02**: Visitor can read testimonials from Podcast studio renters
- [ ] **TRUST-03**: The testimonials section shows a balanced number of quotes for each service line, not skewed toward one
- [ ] **TRUST-04**: Visitor can view a "how it works" process section explaining the steps for engaging the Agency
- [ ] **TRUST-05**: Visitor can view a "how it works" process section explaining the steps for booking the Podcast studio

### Agency Portfolio

- [ ] **PORT-01**: Visitor can view a portfolio/case-study showcase of past Agency work on the Agency page

### Visual Design & UX

- [ ] **DSGN-01**: Every page (Home, Agency, Podcast, Contact) reflects an elevated, polished visual treatment (spacing, hierarchy, imagery, micro-interactions) while keeping the existing Gotham font, orange/gold color theme, and existing graphic elements unchanged
- [ ] **DSGN-02**: Visitor on mobile can navigate and use every page without layout breakage or unusable controls
- [ ] **DSGN-03**: Visitor sees an obvious, low-friction call-to-action to book a call/session on every page

### Site Structure & Cross-Sell

- [ ] **NAV-01**: Agency and Podcast pages have equal structural weight — matching nav treatment, comparable homepage real estate, and comparable content depth (portfolio/gear list, pricing structure, testimonials) so neither reads as secondary
- [ ] **NAV-02**: Visitor on the Agency page can find a cross-sell CTA pointing to the Podcast studio, and vice versa

## Out of Scope

Explicitly excluded. Documented to prevent scope creep.

| Feature | Reason |
|---------|--------|
| Backend / real form submission | Frontend-only project; reservation and contact forms stay UI + validation only, no email service or API integration |
| Real Calendly / live booking integration | Placeholder links remain until backend work happens in a future milestone |
| Authentication, payments, or accounts | Not part of a marketing/booking site scope |
| Automated test suite | Known codebase gap, not part of this redesign's scope |
| Code implementation in this session | This GSD project produces plans/roadmap only; implementation happens in Antigravity CLI |
